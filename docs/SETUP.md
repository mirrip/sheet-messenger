# Настройка Google и push — по кнопкам

Код проекта готовится в GitHub. Владелец Google-аккаунта выполняет только действия ниже. Они нужны один раз.

## 1. Подключить таблицу к Apps Script

1. Откройте проект **Sheet Messenger Backend** в Apps Script.
2. Слева нажмите **Настройки проекта** (значок шестерёнки).
3. Найдите **Свойства скрипта** → **Добавить свойство**.
4. Имя: `SPREADSHEET_ID`.
5. Значение: ID вашей Google Таблицы — часть адреса между `/d/` и `/edit`.
6. Нажмите **Сохранить свойства скрипта**.
7. Вернитесь в редактор, выберите функцию `setupProject` и нажмите **Выполнить**.
8. Разрешите доступ к таблице. Это обязательное разрешение Google; без него закрытая таблица недоступна скрипту.

`setupProject` подготовит листы `Users`, `Devices`, `Messages` и `Config`. Секрет для хэширования паролей создастся автоматически.

## 2. Опубликовать Apps Script

1. Нажмите **Начать развертывание** → **Новое развертывание**.
2. Тип: **Веб-приложение**.
3. Выполнять от имени: **Я**.
4. У кого есть доступ: **Все**.
5. Нажмите **Развернуть** и пройдите разрешение Google.
6. Скопируйте адрес, который заканчивается на `/exec`.

Адрес `/exec` публичный, но чтение сообщений, поиск и отправка требуют действующую сессию пользователя. Этот адрес можно прислать разработчику. Пароли, токены сессий и сервисный JSON присылать нельзя.

## 3. Создать бесплатный Firebase Push

1. Откройте [Firebase Console](https://console.firebase.google.com/) и нажмите **Создать проект**.
2. Google Analytics можно выключить — для push он не нужен.
3. На главной странице проекта нажмите значок **Web `</>`** и зарегистрируйте веб-приложение.
4. Скопируйте объект `firebaseConfig`. Он публичный и будет добавлен в `web/config.js`.
5. Откройте **Настройки проекта** → **Cloud Messaging**.
6. В разделе **Web Push certificates** нажмите **Generate key pair** и скопируйте публичный VAPID-ключ.
7. Если рядом с **Cloud Messaging API (V1)** показана кнопка включения, нажмите её.

`firebaseConfig` и публичный VAPID-ключ можно прислать разработчику. Они не дают права отправлять push сами по себе.

## 4. Добавить секрет отправки push

1. В Firebase откройте **Настройки проекта** → **Сервисные аккаунты**.
2. Нажмите **Создать новый закрытый ключ** и сохраните JSON-файл в безопасном месте.
3. Откройте Apps Script → **Настройки проекта** → **Свойства скрипта**.
4. Добавьте `FCM_SERVICE_ACCOUNT_JSON` и вставьте полное содержимое JSON-файла.
5. Добавьте `WEB_APP_URL` со значением `https://mirrip.github.io/sheet-messenger/`.
6. Сохраните свойства и создайте **новую версию развертывания** Apps Script.

JSON сервисного аккаунта нельзя загружать в GitHub и нельзя отправлять в чат. Он остаётся только в закрытых свойствах Apps Script.

## 5. Включить уведомления на телефоне

### Android

1. Откройте веб-приложение по HTTPS.
2. Войдите в аккаунт.
3. Откройте профиль → **Включить уведомления** → **Разрешить**.

### iPhone

Нужна iOS 16.4 или новее.

1. Откройте веб-приложение в Safari.
2. Нажмите **Поделиться** → **На экран «Домой»**.
3. Запустите приложение с нового значка.
4. Войдите → профиль → **Включить уведомления** → **Разрешить**.

Подписка Apple Developer не нужна. Видимый push отправляется для личных сообщений; общий канал работает без push.
