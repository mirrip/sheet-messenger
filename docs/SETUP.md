# Настройка облачной части

## Что потребуется от владельца проекта

1. Войти в нужный Google-аккаунт.
2. Создать пустую Google Таблицу.
3. Открыть в ней **Расширения → Apps Script**.
4. Разрешить выполнение функции `setupProject`.
5. Создать Firebase-проект и включить Cloud Messaging.
6. Разрешить уведомления на тестовом телефоне.

Секретные ключи и токены не публикуются в GitHub.

## Этапы

### 1. Таблица

Функция `setupProject()` автоматически создаёт листы `Users`, `Devices`, `Messages` и `Config`.

### 2. Apps Script

Код из папки `apps-script` будет загружаться через `clasp`. Развёртывание выполняется от имени владельца Таблицы.

### 3. Push

Firebase/Web Push подключается после проверки обмена сообщениями. У пользователя будет одно основное устройство уведомлений. Первое непрочитанное сообщение отправляет один push; последующие сообщения накапливаются до открытия приложения.

### 4. Безопасность

Текущая версия является техническим прототипом. До приглашения реальных пользователей необходимо добавить одноразовые приглашения, токены устройств, проверку доступа к чатам и ограничение частоты запросов.
