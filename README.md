# Sheet Messenger

Минималистичный мессенджер, в котором Google Apps Script выполняет роль сервера, Google Таблица хранит сообщения, а Web Push/FCM доставляет уведомления.

## Текущее состояние

Рабочий каркас версии 0.3:

- адаптивный веб-интерфейс;
- регистрация и вход по уникальному username и паролю;
- внутренний `user_id` и отдельная сессия устройства;
- изменяемый неподтверждённый номер телефона;
- поиск пользователей только по username;
- личные чаты, которые открываются из поиска;
- пароль хранится как HMAC-хэш с индивидуальной солью и серверным секретом;
- серверный лимит: не больше одного сообщения в секунду от пользователя;
- формат сообщений `text`, `photo` и `video`, включая подпись и метаданные файла;
- обновление сообщений каждые 5 секунд;
- push для личных сообщений на одном основном устройстве пользователя;
- общий канал без push;
- PWA-манифест, Service Worker и публикация через GitHub Pages;
- без внешних библиотек и без секретов в репозитории.

Локальный режим нужен только для проверки интерфейса. Адрес развёрнутого Apps Script и публичные настройки Firebase задаются в `web/config.js`.

На iPhone уведомления работают для приложения, добавленного на экран «Домой» (iOS 16.4 или новее). Подписка Apple Developer не требуется.

## Запуск на компьютере

Требуется Node.js 20 или новее.

```bash
npm run dev
```

После запуска откройте `http://localhost:4173`.

## Структура

```text
docs/         инструкции по настройке
```

## Безопасность

Не добавляйте в репозиторий токены GitHub, ключи Firebase, файлы сервисных аккаунтов, ключи подписи Android и реальные данные пользователей.

Таблица хранит только хэши паролей и сессий, но версия всё ещё является прототипом и не проходила независимый аудит безопасности. Сами фото и видео в Google Таблицу не записываются: в сообщении хранится только ссылка/ID файла и его метаданные.

Публичный Firebase Web Config и публичный VAPID-ключ можно хранить в `web/config.js`. JSON сервисного аккаунта Firebase — секрет: он хранится только в свойствах Apps Script.

## Что пока не готово

- группы и каналы с участниками;
- загрузка фото и видео в закрытое файловое хранилище (формат сообщений уже предусмотрен);
- восстановление пароля;
- подтверждение телефона;
- независимый аудит безопасности.

Пошаговая ручная настройка Google и Firebase: [docs/SETUP.md](docs/SETUP.md).
