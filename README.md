# Sheet Messenger

Минималистичный мессенджер, в котором Google Apps Script выполняет роль сервера, Google Таблица хранит сообщения, а Web Push/FCM доставляет уведомления.

## Текущее состояние

Первый рабочий каркас:

- адаптивный веб-интерфейс;
- локальный демонстрационный чат;
- обновление сообщений каждые 5 секунд;
- PWA-манифест и Service Worker;
- серверный прототип Apps Script для записи и синхронизации сообщений;
- без внешних библиотек и без секретов в репозитории.

Локальный режим нужен только для проверки интерфейса. После подключения Google Таблицы данные будут передаваться через Apps Script.

## Запуск на компьютере

Требуется Node.js 20 или новее.

```bash
npm run dev
```

После запуска откройте `http://localhost:4173`.

## Структура

```text
web/          интерфейс и PWA
apps-script/  сервер Google Apps Script
scripts/      локальные инструменты разработки
docs/         инструкции по настройке
```

## Безопасность

Не добавляйте в репозиторий токены GitHub, ключи Firebase, файлы сервисных аккаунтов, ключи подписи Android и реальные данные пользователей.
